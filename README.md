# wc26-live — รายงานประตูสดบอลโลก 2026 เข้า Telegram

เช็คสกอร์จาก football-data.org ทุก ~5 นาทีช่วงมีบอลเตะ (เวลาไทย 23:00–13:55) แล้วส่งเข้ากลุ่ม:

- 🔛 เกมเริ่ม
- ⚽ ทุกครั้งที่สกอร์เปลี่ยน (บอกฝั่งที่ยิง)
- ⏸️ หมดครึ่งแรก

ส่วน "จบเกม" ประกาศโดยระบบหลัก (wc26-bot) จึงไม่ส่งซ้ำจากที่นี่ — `live_state.json` คือความจำกันส่งซ้ำ (workflow commit เอง ห้ามแก้มือ)

หมายเหตุ: ความสดหน่วงราว 3–15 นาทีต่อเหตุการณ์ ตามรอบ cron ของ GitHub + ความเร็วข้อมูลของ football-data ชั้นฟรี

## Secrets ที่ต้องตั้ง

`BOT_TOKEN`, `CHAT_ID`, `FOOTBALL_DATA_TOKEN` (ค่าเดียวกับใน wc26-bot)
