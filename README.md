# wc26-live — รายงานประตูสดบอลโลก 2026 เข้า Telegram

โหมด long-poll: workflow ถูกปลุกทุก 30 นาทีช่วงมีบอลเตะ (เวลาไทย 23:00–13:55) แล้ว**วนเช็คเองทุก 60 วินาที**ภายในรอบ จึงรายงานเหตุการณ์ได้ภายใน ~1–3 นาที (เร็วสุดเท่าที่ทำได้แบบฟรี) แล้วส่งเข้ากลุ่ม:

- 🔛 เกมเริ่ม
- ⚽ ทุกครั้งที่สกอร์เปลี่ยน (บอกฝั่งที่ยิง)
- ⏸️ หมดครึ่งแรก / ▶️ เริ่มครึ่งหลัง

ส่วน "จบเกม" ประกาศโดยระบบหลัก (wc26-bot) จึงไม่ส่งซ้ำจากที่นี่ — `live_state.json` คือความจำกันส่งซ้ำ (สคริปต์ commit เองทุกครั้งที่มีเหตุการณ์ ห้ามแก้มือ) ถ้าไม่มีบอลกำลังเตะและไม่มีนัดใกล้เริ่ม รอบนั้นจะจบตัวเองทันทีเพื่อไม่เปลืองเครื่อง

## Secrets ที่ต้องตั้ง

`BOT_TOKEN`, `CHAT_ID`, `FOOTBALL_DATA_TOKEN` (ค่าเดียวกับใน wc26-bot)
